# TissueSeg3D
A Napari based tool to segment cells and nuclei in a 3D stack with membrane and nuclear labels (2 fluo channels)

Installation
------------

1) Install latest miniconda: https://www.anaconda.com/docs/getting-started/installation
2) Clone this repository or download it as a ZIP file (green button) and unzip to an empty folder
3) Launch Anaconda Prompt (Windows) or Terminal (Mac/Linux) and run these commands:

```bash
cd PATH_TO_REPO_FOLDER (update with path to the repository folder)
conda create -n tissueseg3d python=3.10
conda activate tissueseg3d
pip install -r requirements.txt
```

Running
-------

Launch Anaconda Prompt (Windows) or Terminal (Mac/Linux) and run these commands:

```bash
cd PATH_TO_REPO_FOLDER (update with path to the repository folder)
conda activate tissueseg3d
python -m main.py
```
